# 小米遥控器 · vibe coding 工具 使用说明

把 **65 块的小米蓝牙遥控器 2 Pro** 变成 Windows 上的 AI 编程遥控器：
躺在沙发上按住遥控器说话指挥 Claude Code / ZCode / Codex，
方向键翻结果、OK 批准、返回键打断、音量键调音量。

---

## 一、准备（只需一次）

### 必需
1. **Windows 10 1809+ 电脑**（带蓝牙）
2. **小米蓝牙遥控器 2 Pro（RC003）**——小米官网 99 元 / 闲鱼约 65 元
3. 蓝牙配对：**同时长按遥控器【主页键+菜单键】**直到指示灯闪烁，
   在 Windows「设置 → 蓝牙和其他设备」里添加

### 按需（用微信语音模式才需要）
- **VB-CABLE 虚拟声卡**（免费）：https://vb-audio.com/Cable/ 下载安装，重启电脑
- **微信输入法（电脑版）**：https://z.weixin.qq.com/ 安装并登录
- 在微信输入法设置里，把**语音输入的麦克风**改成 **「CABLE Output (VB-Audio Virtual Cable)」**

---

## 二、日常使用

### 启动
双击 **`小米遥控器.exe`** → 点「启动守护」→ 状态显示 **"运行中"** 即可。

首次启动会弹一次 **UAC 管理员授权**（拦截返回键需要），点「是」。

### 遥控器按键（默认配置）

| 遥控器按键 | 效果 |
|---|---|
| **按住语音键说话，松手** | **语音输入**（文字自动打进光标处） |
| 方向键 ↑↓←→ | 光标移动 / 翻阅 AI 对话 |
| OK（中间圆键） | 回车（批准 AI 操作） |
| **返回键** | **Esc（打断 AI）** |
| 音量 + / − | 电脑音量 |
| TV | Alt+Tab 切窗口 |
| 主页 / 菜单 / 电源 | Home / 菜单键 / 无操作（可自定义） |

### 两种语音模式（软件里可切换）

| | 本地模式（默认） | 微信语音模式 |
|---|---|---|
| 需要装什么 | 什么都不用 | VB-CABLE + 微信输入法 |
| 联网 | 不用 | 要 |
| 速度 | 松手后约 3 秒 | 松手后约 4-6 秒 |
| 特色 | 全程离线、隐私 | **自动去语气词、整理语句** |
| 准确率 | 偶有错字 | 明显更好 |

切换方法：软件 → 「语音」页 → 模式下拉框选择 → 重启守护。

### 关闭软件
- 点窗口 × → **缩到系统托盘继续后台运行**（不影响使用遥控器）
- 想彻底退出：托盘右键 → 退出

## 三、实用设置

### 开机自动启动（推荐）
「控制」页勾选 **「开机自动启动（后台静默运行）」**。
开机后软件静默驻留后台、自动启动守护，拿起遥控器直接用。

### 隐藏托盘图标
托盘右键 → 「隐藏托盘图标」。
程序继续后台运行；**想找回窗口：再次双击 小米遥控器.exe**。

### 自定义按键功能
「按键映射」页 → 点遥控器图或列表选一个键 → 动作下拉框：
- 选预设（Esc 打断、复制、粘贴、切权限…）
- 「录制组合键…」：弹窗里按下你的组合键（如 Ctrl+Alt+T）
- 「输入文本…」/「运行程序…」：填内容即可
- 点「保存此键」生效

## 四、常见问题

**Q：Windows 提示"已保护你的电脑"？**
程序没有买代码签名证书，属正常。点「更多信息」→「仍要运行」。

**Q：杀毒软件报警？**
返回键拦截用了"进程注入"技术，特征像病毒但不是。加信任即可。

**Q：启动守护后返回键没反应？**
UAC 被拒绝或杀软拦截了注入。重启软件再试一次，UAC 点「是」。

**Q：微信模式没反应？**
按顺序检查：①VB-CABLE 装了没、重启过没；②微信输入法设置里麦克风是否已选
「CABLE Output」；③软件「语音」页是否切到了微信模式并重启了守护。

**Q：本地语音识别有错字？**
「语音」页把模型换成 large-v3（更准更慢），或切微信模式。

**Q：配置文件在哪？**
`C:\Users\你的用户名\AppData\Roaming\MiRemoteVibe\config.json`
删掉它 = 恢复默认。
